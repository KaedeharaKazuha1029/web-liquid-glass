ZERO RUNTIME DEPENDENCIES

一个组件，接入任何普通网页。

保留真实 DOM 按钮负责语义和点击，WebGL Canvas 只负责光学合成。 场景变化、滚动、图片加载与尺寸变化都会自动刷新采样纹理。 

import { liquidGlass } from "web-liquid-glass";
import "web-liquid-glass/styles.css";

const glass = liquidGlass("#nav", {
  sceneRoot: "#app",
});
